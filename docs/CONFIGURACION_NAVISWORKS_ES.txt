No es necesario volver a Navisworks en inglés ni renombrar manualmente el XML.
El dashboard reconoce Element / Elemento / Componente y Category / Categoría,
Family / Familia, Volume / Volumen. También lee el ID desde objectattribute.
Los nombres personalizados configurados tienen prioridad cuando aportan un valor.

Pasos para recuperar las propiedades ausentes:
1. Seleccionar un elemento EST y uno ACI en Navisworks y comprobar sus propiedades.
2. En propiedades rápidas, elegir cada propiedad desde la lista real del modelo.
   Revisar Contenedor Origen, Edificio, Zona, Sector, Ambiente y Tipo de elemento.
   Si el valor no existe en el modelo, corregirlo en el modelo de origen y actualizar
   el vínculo antes de volver a exportar. El dashboard no puede reconstruirlo.
3. Revisar ID Partida N°01 y Unidad Medida N°01. El archivo de parámetros recibido
   tiene N?01 en sus identificadores internos. Volver a seleccionarlos y exportar
   la configuración desde Navisworks para obtener los identificadores reales.
4. Generar el informe XML del test completo, incluyendo todos sus estados y las
   propiedades/IDs de los objetos disponibles. Comprobar el resumen del XML.
5. Cargar el informe con Cargar más o actualizar el XML del corte correspondiente.
   Una carga del mismo test sustituye su versión previa en la sesión, incluidos
   cambios de estado de GUID existentes; los demás tests permanecen presentes.
